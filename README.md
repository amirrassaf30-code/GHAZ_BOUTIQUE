# راهنمای فروشگاه

## ساختار فایل‌ها
- `js/config.js` : نام فروشگاه، دامنه، شماره کارت، شماره واتساپ، لینک درگاه (اختیاری)
- `js/products.js` : کالکشن‌ها و محصولات (فقط این فایل را برای تغییر محصول ویرایش کن)
- `js/app.js` : منطق سایت (معمولاً لازم نیست تغییرش دهی)
- `css/style.css` : ظاهر و انیمیشن‌ها
- `index.html` و `product.html` : صفحات سایت

## انتشار در گیت‌هاب (GitHub Pages)
1. یک Repository جدید بساز و همه فایل‌ها را آپلود کن.
2. از Settings > Pages، Source را روی `main` و پوشه `/ (root)` بگذار.
3. آدرس سایت به شکل `https://username.github.io/repo-name` ساخته می‌شود.
4. بعد از تغییر هر فایل، Commit کن تا سایت به‌روز شود (چند دقیقه طول می‌کشد).

## تغییر دامنه
1. در `js/config.js` مقدار `domain` را به دامنه جدید تغییر بده.
2. اگر دامنه اختصاصی داری: در Settings > Pages بخش Custom domain را پر کن و یک فایل به نام `CNAME` (با یک خط: نام دامنه) در ریشه پروژه بساز.

## پرداخت
- **کارت به کارت:** شماره کارت و نام صاحب حساب را در `config.js` بنویس. مشتری بعد از واریز، رسید را همراه سفارش به واتساپ شما می‌فرستد.
- **درگاه آنلاین:** اگر لینک پرداخت آماده‌ای از یک درگاه داری، در `paymentLink` قرار بده.

## نکته امنیتی
سایت استاتیک است؛ هر چیزی که در فایل‌های JS باشد برای بازدیدکننده قابل مشاهده است. کلیدهای API یا رمز حساب را هرگز در این فایل‌ها نگذار.
